#### Fix #6a — `_disposed` checked outside write semaphore; `Dispose()` order is wrong (CRITICAL)

**File**: `SqliteRepository.cs:192`, `250`, `319`, `336`, `367-373`  
**Issue**: `_disposed` is read before `WaitAsync`; a context switch between the check and the wait lets `Dispose()` run first, then `WaitAsync` throws on a disposed semaphore or proceeds to use a disposed connection. **Before** (`SqliteRepository.cs:190-244` — `InsertAuditEventAsync` shown; same pattern in `UpsertBaselineAsync`, `DeleteBaselineAsync`, `SetConfigValueAsync`):
```csharp

{

    await _writeLock.WaitAsync();
    try
    {
        using var tx = _conn.BeginTransaction();
        ...
        tx.Commit();
    }
    finally { _writeLock.Release(); }
}
```

**Before** (`SqliteRepository.cs:367-373` — `Dispose`):
```csharp
public void Dispose()
{
    _disposed = true;
    _writeLock.Dispose();
    _conn.Dispose();
    _readConn.Dispose();
}
```

**After** (`InsertAuditEventAsync` — apply identical pattern to the other three write methods):
```csharp
public async Task InsertAuditEventAsync(AuditLogEntry e, FileBaseline baseline)
{
    if (_disposed) return;
    try { await _writeLock.WaitAsync(); }
    catch (ObjectDisposedException) { return; }   // disposed between check and wait
    try
    {
        if (_disposed) { _writeLock.Release(); return; }   // re-check under logical lock
        using var tx = _conn.BeginTransaction();
        ...
        tx.Commit();
    }
    catch (ObjectDisposedException) when (_disposed) { }   // shard evicted mid-write — silent
    finally { _writeLock.Release(); }
}
```

**After** (`Dispose` — corrected disposal order):
```csharp

{
    _disposed = true;
    // Drain the semaphore so any in-progress write can finish before we close connections.
    try { _writeLock.Wait(TimeSpan.FromSeconds(5)); } catch { }
    _conn.Dispose();
    _readConn.Dispose();
    _writeLock.Release();
    _writeLock.Dispose();
}
```

**Why**: Catching `ObjectDisposedException` on `WaitAsync` handles the TOCTOU window; the second `_disposed` check inside the `try` block catches the race after the wait completes; reversing `_writeLock.Dispose()` to after connection disposal ensures in-flight writers can complete their `finally { Release() }` without throwing on a disposed semaphore.

### Fix #32 — `UpsertBaselineAsync` runs without an explicit transaction (Medium)

**Agents**: storage (M2)  
**File**: `SqliteRepository.cs:247-269`  
**Issue**: The single-statement upsert is implicitly autocommit; future batching without an explicit transaction would lose rollback coverage.

**Before** (`SqliteRepository.cs:248-268`):
```csharp

{

    await _writeLock.WaitAsync();
    try
    {
        using var cmd = _conn.CreateCommand();
        cmd.CommandText = @"
            INSERT INTO file_baselines (filepath, last_hash, last_seen, last_content)
            VALUES (@fp, @lh, @ls, @lc)
            ON CONFLICT(filepath) DO UPDATE SET
              last_hash    = excluded.last_hash,
              last_seen    = excluded.last_seen,
              last_content = excluded.last_content";
        cmd.Parameters.AddWithValue("@fp", baseline.Filepath);
        cmd.Parameters.AddWithValue("@lh", baseline.LastHash);
        cmd.Parameters.AddWithValue("@ls", baseline.LastSeen);
        cmd.Parameters.AddWithValue("@lc", (object?)baseline.LastContent ?? DBNull.Value);
        await cmd.ExecuteNonQueryAsync();
    }
    finally { _writeLock.Release(); }
}
```

**After**:
```csharp
public async Task UpsertBaselineAsync(FileBaseline baseline)
{
    if (_disposed) return;
    try { await _writeLock.WaitAsync(); }
    catch (ObjectDisposedException) { return; }
    try
    {
        if (_disposed) { _writeLock.Release(); return; }
        using var tx  = _conn.BeginTransaction();
        using var cmd = _conn.CreateCommand();
        cmd.Transaction = tx;
        cmd.CommandText = @"
            INSERT INTO file_baselines (filepath, last_hash, last_seen, last_content)
            VALUES (@fp, @lh, @ls, @lc)
            ON CONFLICT(filepath) DO UPDATE SET
              last_hash    = excluded.last_hash,
              last_seen    = excluded.last_seen,
              last_content = excluded.last_content";

        cmd.Parameters.AddWithValue("@lh", baseline.LastHash);
        cmd.Parameters.AddWithValue("@ls", baseline.LastSeen);
        cmd.Parameters.AddWithValue("@lc", (object?)baseline.LastContent ?? DBNull.Value);

        tx.Commit();
    }
    catch (ObjectDisposedException) when (_disposed) { }
    finally { _writeLock.Release(); }
}
```

**Why**: An explicit transaction makes the intent clear, enables easy extension to batch upserts, and applies the same TOCTOU-safe pattern introduced in Fix #6a.
